# Brouillons

Déposez ici les fiches en cours de rédaction, plutôt que dans `src\data\realisations\`.

**Pourquoi.** Sur un compte GitHub gratuit, le dépôt qui publie le site doit être **public** : tout
son contenu est lisible par n'importe qui. Une fiche marquée `brouillon: true` n'apparaît pas sur le
site — mais son fichier, lui, se lit dans le dépôt. Un brouillon n'est donc discret que tant qu'il
n'a pas été envoyé.

Ce dossier est exclu du dépôt (`.gitignore`). Ce qui s'y trouve ne quitte pas votre ordinateur.

**Le geste.** Rédigez ici. Quand la pièce est prête, déplacez le fichier dans
`src\data\realisations\` et passez `brouillon` à `false`. Les images, elles, peuvent rester dès le
départ dans `src\assets\` : une image sans fiche n'est jamais servie.
