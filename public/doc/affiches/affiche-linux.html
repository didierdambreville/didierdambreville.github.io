01Anatomie d’une commande

aliceutilisateur
@
pcmachine
:
~/docsdossier courant
$invite
lscommande
-lhoptions
/var/logargument
  • $ : utilisateur ordinaire · # : administrateur (root).
  • Options groupables : -l -h = -lh.
  • La casse compte : ls -r ≠ ls -R.
  • Aide : man ls (q pour quitter) · ls --help.

02Se déplacer

pwdoù suis-je ?
ls -llister : droits, taille, date
ls -aavec les fichiers cachés
cd dossierentrer dans un dossier
cd ..remonter d’un niveau
cdrevenir chez soi (~)
cd -revenir au dossier précédent

03Fichiers

mkdir -p a/bcréer des dossiers
cp src destcopier (-r : un dossier)
mv ancien nouveaurenommer, déplacer
rm fichiersupprimer
cat f · less fafficher · lire page par page

Pas de corbeille : rm est définitif et rm -rf ne demande rien.

04Les droits

-type
rwxpropriétaire
r-xgroupe
r-xautres
r = 4 · w = 2 · x = 1un chiffre par catégorie : rwx = 7, r-x = 5 → 755
chmod +x script.shrendre exécutable
chmod 600 ffichier privé (clé SSH)

chmod 777 : tout à tous, à proscrire.

05Enchaîner

cmd > fécrire dans f (l’écrase)
cmd >> fajouter à la fin de f
a | btube : la sortie de a nourrit b
a && bb seulement si a réussit
cmd 2>/dev/nulljeter les erreurs

06Raccourcis
