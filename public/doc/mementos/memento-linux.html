Anatomie d’une commande

lscommande
-l -hoptions
/var/logargument
  • Options courtes groupables : -l -h = -lh ; forme longue : --human-readable.
  • La casse compte : ls -r (ordre inverse) ≠ ls -R (récursif).
  • -- clôt les options : rm -- -fichier.
  • Espace dans un nom : cd "Mes documents" ou cd Mes\ documents.
  • Code de retour : 0 = succès, toute autre valeur = échec → echo $?.

Pratiquer sans risque

  • Machine virtuelle avec instantanés : on revient en arrière après une erreur.
  • WSL sous Windows : pratique pour s’exercer, mais n’isole pas du système hôte.
  • Clé USB « live » : Linux démarre sans installation.
  • Provoquer les erreurs volontairement, au laboratoire, pour apprendre à les lire.
  • ! Ne jamais expérimenter avec sudo sur une machine dont on dépend.

Démarche de diagnostic

  1. Lire le message en entier : la première erreur est souvent la vraie.
  2. Code de retour : echo $?.
  3. Plus de détails : -v, --verbose, bash -x.
  4. Journaux : journalctl -u service -e, /var/log/.
  5. Vérifier l’évidence : chemin, droits, espace, service, réseau.
  6. Ne changer qu’une chose à la fois, puis retester.

À manier avec précaution

rm -rf cheminsuppression définitive, sans question : relire le chemin

Règle d’or : comprendre chaque option avant Entrée ; simuler d’abord (--dry-run, -i, echo) ; ne jamais coller une commande que l’on ne comprend pas.

Lire une ligne de ls -l

droits
-rwxr-x---1alicecompta4096Sep 28 10:15rapport.sh
typepropriétaire ugroupe gautres olienspropriétairegroupetaille (octets)dernière modificationnom

Type : - fichier · d dossier · l lien symbolique · b c périphérique (bloc, caractère) · p tube nommé · s socket. Droits dans l’ordre r lire · w écrire · x exécuter ; - = droit absent.

Que signifient r, w, x ?

sur un fichiersur un dossier
r (4)lire le contenulister les noms (ls)
w (2)modifier le contenucréer, renommer, supprimer des éléments
x (1)exécuter (programme, script)entrer (cd) et accéder aux éléments

Supprimer un fichier dépend des droits sur le dossier qui le contient, pas sur le fichier lui-même.

Notation octale

0 ---1 --x2 -w-3 -wx4 r--5 r-x6 rw-7 rwx
644rw-r--r--fichier ordinaire
600rw-------fichier privé (clé SSH)
755rwxr-xr-xprogramme, script, dossier
700rwx------dossier privé (~/.ssh)
664 · 775rw-rw-r-- · rwxrwxr-xtravail en groupe
777rwxrwxrwx! tout à tous : à proscrire

Un chiffre par catégorie u · g · o ; chaque chiffre = somme de r 4 + w 2 + x 1. Ex. 6 = 4 + 2 = rw-.

Modifier droits et propriétaires

chmod 644 ffixer les droits en octal
chmod u+x fajouter x au propriétaire
chmod g-w fretirer w au groupe
chmod o= fretirer tout droit aux autres
chmod a+r flecture pour tous (a = u + g + o)
chmod u=rw,go=r ffixer chaque catégorie (= 644)
chmod -R u+rwX drécursif ; X : x pour les dossiers seulement (et fichiers déjà exécutables)
sudo chown util fchanger le propriétaire
sudo chown util:groupe fpropriétaire et groupe
sudo chown -R util: drécursif ; groupe principal de util
chgrp groupe fchanger le groupe (si l’on en est membre)

! chmod -R 777 ne résout rien : il ouvre tout à tous. Chercher plutôt qui doit accéder, et à quoi.

Masque et droits spéciaux

umaskmasque appliqué aux créations ; souvent 0022 → fichiers 644, dossiers 755 (ou 0002 → 664, 775)
chmod u+s fsetuid (4000) : le programme s’exécute avec les droits de son propriétaire (ex. passwd)
chmod g+s dsetgid (2000) sur un dossier : les nouveaux fichiers héritent de son groupe
chmod +t dsticky (1000) : seul le propriétaire d’un fichier peut le supprimer (ex. /tmp : drwxrwxrwt)

s ou t minuscule : bit spécial avec x ; S ou T majuscule : bit spécial sans x.

Squelette d’un script

#!/usr/bin/env bash
# sauvegarde.sh — archive datée d’un dossier
set -euo pipefail

dossier="${1:?usage : $0 dossier}"
dest="$HOME/sauvegardes"
jour="$(date +%F)"                  # AAAA-MM-JJ
archive="$dest/$(basename "$dossier")-$jour.tar.gz"

mkdir -p "$dest"
tar -czf "$archive" "$dossier"
echo "Archive créée dans $dest"

Bonnes pratiques

  • Guillemets doubles autour de chaque variable : "$f".
  • [[ ]] plutôt que [ ] en Bash ; $( ) plutôt que les accents graves.
  • Variables en minuscules : les majuscules désignent l’environnement (PATH, HOME).
  • Tester sur des copies ; préfixer d’un echo une commande destructrice pour voir ce qu’elle ferait.
  • Script lancé par cron : chemins absolus (page 7).
  • ! Avec set -e, (( n++ )) arrête le script quand n vaut 0 (l’expression vaut « faux ») → n=$(( n + 1 )).
