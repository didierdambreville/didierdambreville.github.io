Prononcer

Deux usages : la prononciation restituée (latin classique, usage scolaire et universitaire) et la prononciation ecclésiastique, à l’italienne (liturgie, chant). Toutes les lettres se prononcent : ni voyelle nasale, ni e muet — templum « tèmploum ».

Accent tonique

  • Jamais sur la dernière syllabe (sauf monosyllabes).
  • Mots de 2 syllabes : accent sur la première — RO‑sa, A‑mo.
  • 3 syllabes et plus — loi de la pénultième : accent sur l’avant-dernière si elle est longue (a-MĪ‑cus ; pu-EL‑la, longue « par position » : voyelle + 2 consonnes), sinon sur l’antépénultième (DO‑mi-nus, LE‑gi-mus).
  • ‑que, ‑ne, ‑ve collés à un mot attirent l’accent sur la syllabe qui les précède : po-pu-LUS‑que.

Ce qui change du français

  • Pas d’article : rosa = la rose, une rose.
  • Le pronom sujet est dans la terminaison : amo = j’aime ; ego amo insiste (moi, j’aime).
  • Ordre des mots libre : la terminaison, non la place, donne la fonction. Verbe souvent en fin de proposition.
  • L’adjectif s’accorde en genre, nombre et cas, sans avoir forcément la même terminaison : agricola bonus, le bon paysan. !
  • ‑que collé au second mot = « et » : senatus populusque. ‑ne pose une question : Venisne ? Viens-tu ?

Traduire : la méthode

  1. Lire toute la phrase ; repérer ponctuation, mots de liaison, conjonctions, relatifs.
  2. Encadrer les verbes conjugués : un verbe = une proposition. Distinguer principale et subordonnées.
  3. Analyser chaque verbe : personne, nombre, temps, mode, voix.
  4. Chercher le sujet au nominatif, accordé avec le verbe (souvent sous-entendu).
  5. Chercher le COD à l’accusatif, puis les autres compléments (cas, prépositions).
  6. Regrouper les mots accordés : adjectif et nom de même genre, nombre et cas.
  7. Traduire mot à mot, puis réécrire en bon français.

Reconnaître la déclinaison

1regénitif en ‑aerosa, ae
2egénitif en ‑īdominus, i ; templum, i
3egénitif en ‑isconsul, is ; mare, is
4egénitif en ‑ūsfructus, us
5egénitif en ‑eī / ‑ēīres, rei ; dies, diei

Règles d’or

  • Neutre : nominatif = vocatif = accusatif ; au pluriel, toujours ‑a.
  • Datif pluriel = ablatif pluriel.
  • Vocatif = nominatif, sauf 2e décl. en ‑us : domine ; en ‑ius : fili.
  • Génitif pluriel : ‑ārum, ‑ōrum, ‑um / ‑ium, ‑uum, ‑ērum.
  • 3e décl. : nominatif imprévisible — apprendre le génitif.

Genre

  • 1re : féminin ; masculins les noms d’hommes (agricola, nauta, poeta).
  • 2e : ‑us, ‑er masculins, ‑um neutres ; noms d’arbres, de villes, de pays en ‑us féminins (pirus, Corinthus).
  • 3e : à apprendre avec le mot. Repères : ‑or m. (timor) ; ‑io, ‑tas, ‑tus, ‑tudo f. (natio, civitas, virtus) ; ‑men et ‑us (gén. ‑oris, ‑eris) n. (nomen, tempus, genus).
  • 4e : masculin ; manus, domus f. ; en ‑ū neutres (cornu, genu).
  • 5e : féminin, sauf dies, meridies (m.).

3e déclinaison : deux familles

  • Imparisyllabiques (plus de syllabes au génitif qu’au nominatif) : Acc ‑em, Abl ‑e, G pl. ‑um, neutre pl. ‑a — consul, corpus, rex, nomen.
  • Thèmes en ‑i : G pl. ‑ium. Ce sont les parisyllabiques en ‑is, ‑es (civis, civis ; nubes, nubis) et les monosyllabes à radical en deux consonnes (urbs, urbis ; mons, montis ; nox, noctis).
  • Neutres en ‑e, ‑al, ‑ar (mare, animal, exemplar) : Abl ‑ī, pl. ‑ia, G pl. ‑ium.
  • !G pl. en ‑um malgré tout : pater, mater, frater, canis, iuvenis, senex → patrum, canum…

Particularités

  • domus, ūs, f. (maison) : domi (à la maison), domum (à la maison, avec mouvement), domo (de la maison).
  • deus, ī : voc. deus ; N pl. di (dei), D Abl pl. dis (deis).
  • ‑ius : voc. fili (ô fils), Vergili ; meus → mi : mi fili.
  • filia, dea : D Abl pl. filiabus, deabus (≠ filiis, deis).
  • vis, f. (force) : Acc vim, Abl vi ; pl. vires, virium (forces). !≠ vir, viri (homme).
  • Iuppiter, Iovis ; bos, bovis (bœuf).
  • res publica, rei publicae, f. : l’État — les deux mots se déclinent.

Pluriels à retenir

  • Sans singulier : arma, orum n. (armes) ; castra, orum n. (camp) ; liberi, orum m. (enfants) ; divitiae, arum f. (richesses) ; insidiae, arum f. (embuscade).
  • Sens nouveau au pluriel : copia abondance / copiae troupes ; littera lettre de l’alphabet / litterae lettre (missive), littérature ; finis fin / fines territoire ; auxilium aide / auxilia troupes auxiliaires ; opem aide / opes ressources.

Trois familles

  • À 2 terminaisons : fortis, e ; omnis (tout), brevis (court), gravis (lourd).
  • À 3 terminaisons : acer, acris, acre (vif) ; seul le N sg. distingue m. acer et f. acris ; celer, celeris, celere garde le e.
  • À 1 terminaison : prudens, entis ; felix, icis (heureux) ; ingens, entis (immense) ; audax, acis (audacieux).
  • !vetus, eris (vieux), dives, itis (riche), pauper, eris (pauvre), princeps, ipis : Abl ‑e, G pl. ‑um.
  • Participe présent (amans, antis) : Abl en ‑e ; en ‑ī s’il est employé comme adjectif.

Adverbes

  • 1re classe : radical + ‑ē : libere, pulchre ; !bonus → bene, malus → male.
  • 2e classe : radical + ‑iter : fortiter, acriter ; ‑ns → ‑nter : prudenter.
  • Comparatif = neutre du comparatif : fortius ; superlatif en ‑issimē : fortissime.
  • Irréguliers : bene, melius, optime ; male, peius, pessime ; multum, plus, plurimum ; magis, maxime ; parum, minus, minime ; diu, diutius, diutissime.

Comparatif et superlatif

  • Comparatif : radical + ‑ior (m. f.), ‑ius (n.) ; G ‑iōris : altus → altior, altius (plus haut). Il suit consul / corpus : Abl altiore, n. pl. altiora, G pl. altiorum.
  • Superlatif : radical + ‑issimus, a, um : altissimus (très haut, le plus haut).
  • En ‑er : ‑errimus (pulcherrimus, acerrimus). facilis, difficilis, similis, dissimilis, gracilis, humilis : ‑illimus (facillimus).
  • Complément : quam + même cas, ou ablatif : altior quam Paulus = altior Paulo.
  • Superlatif relatif : génitif ou e/ex + abl. : doctissimus omnium, le plus savant de tous. quam + superlatif : le plus… possible (quam celerrime).

Les trois radicaux du verbe — amo, as, are, avi, atum

Radical du présent ama- — système de l’infectum (action en cours) : présent, imparfait, futur ; subjonctif présent et imparfait ; impératif ; infinitif présent ; participe présent ; gérondif ; adjectif verbal.
Radical du parfait amav- — système du perfectum (action achevée) : parfait, plus-que-parfait, futur antérieur ; subjonctif parfait et plus-que-parfait ; infinitif parfait actif.
Radical du supin amat- — participe parfait passif (amatus), participe futur (amaturus), supin — et, par le participe, tout le passif du perfectum.

Déponents

Forme passive, sens actif : hortor, j’exhorte.

  • 1re : hortor, ārī, ātus sum (exhorter) ; conor (essayer), miror (admirer, s’étonner), arbitror (penser).
  • 2e : vereor, ērī, veritus sum (craindre) ; polliceor, pollicitus (promettre) ; fateor, fassus (avouer).
  • 3e : sequor, ī, secutus sum (suivre) ; loquor, locutus (parler) ; utor, usus (se servir de) ; nascor, natus (naître) ; proficiscor, profectus (partir) ; obliviscor, oblitus (oublier).
  • 3e mixte : patior, ī, passus sum (souffrir) ; morior, mortuus (mourir) ; ingredior, ingressus (entrer).
  • 4e : potior, īrī, potitus sum (s’emparer de) ; experior, expertus (éprouver) ; mentior, mentitus (mentir).
  • Formes actives : participes présent (sequens) et futur (secuturus), gérondif, supin. Participe parfait à sens actif : secutus, ayant suivi.
  • + ablatif : utor, fruor, fungor, potior, vescor.
  • Semi-déponents (parfait passif) : audeo, ausus sum (oser) ; gaudeo, gavisus sum (se réjouir) ; soleo, solitus sum (avoir l’habitude) ; fido, fisus sum (se fier).

Sum et ses composés

  • sum, es, esse, fuī ; participe futur futurus ; infinitif futur futurum esse = fore.
  • absum être absent · adsum être présent · desum manquer · intersum assister à · praesum commander (+ dat.) · supersum survivre.
  • prosum être utile : prod- devant voyelle (prodest). possum : pot- devant voyelle, pos- devant s.
  • Datif de possession : Est mihi liber, j’ai un livre.

Défectifs et impersonnels

  • Parfaits à sens présent : odi (je hais), memini (je me souviens ; impér. memento), novi (je sais, de nosco). coepi : j’ai commencé.
  • inquit : dit-il (en incise) ; ait, aiunt : dit-il, dit-on. ave, salve, vale : salut !, bonjour !, adieu !
  • oportet il faut · licet il est permis · decet il convient · placet il plaît, on décide.
  • pudet, paenitet, taedet, piget, miseret + Acc de la personne, G de la cause : me pudet stultitiae, j’ai honte de ma sottise.
  • Passif impersonnel : pugnatur on combat ; itur on va.

Emplois des cas

  • Accusatif : COD ; direction (in urbem, Romam) ; durée (tres annos, pendant trois ans) ; étendue (mille passus) ; exclamation (O me miserum !) ; sujet de l’infinitive ; double Acc (doceo pueros grammaticam).
  • Génitif : complément du nom (amor patriae) ; partitif (pars militum ; satis pecuniae) ; qualité (vir magni ingenii) ; estime (magni aestimare) ; « c’est le propre de » (est regis) ; après cupidus, peritus, memor, plenus ; memini, obliviscor, misereor.
  • Datif : attribution (do librum puero) ; intérêt (non scholae sed vitae discimus) ; possession (est mihi) ; double datif (auxilio venire, venir en aide ; curae esse) ; agent de l’adjectif verbal ; après utilis, similis, carus et pareo, parco, credo, noceo, faveo, invideo, persuadeo, impero, studeo.
  • Ablatif : moyen (gladio) ; manière (magna cura, cum cura) ; cause (fame perire) ; accompagnement (cum amicis) ; agent (a patre) ; origine, séparation (ex urbe ; liberare periculo) ; temps « quand » (prima luce) ; comparaison (Paulo altior) ; qualité (vir summa virtute) ; point de vue (natione Gallus) ; prix (magno emere) ; après utor, fruor, fungor, potior, vescor ; dignus, careo, egeo, opus est.

Questions de temps

  • quando ? quand : ablatif — prima luce, eo anno, hieme.
  • quamdiu ? pendant combien de temps : accusatif — tres annos (ou per + acc.).
  • quamdudum ? depuis quand : Acc + ordinal — tertium annum regnat, il en est à sa troisième année de règne.
  • en combien de temps ? ablatif — paucis diebus, en peu de jours.
  • Il y a : abhinc + acc. — abhinc tres annos. Avant, après : ante, post + acc. ; tribus annis post, trois ans après ; post urbem conditam, après la fondation de la Ville.

Interrogation indirecte

  • Mot interrogatif + subjonctif : Nescio quid faciat, je ne sais pas ce qu’il fait.
  • num, ‑ne : si ; utrum… an : si… ou si ; nescio an : peut-être.

Proposition infinitive

  • Après les verbes de parole, pensée, perception, sentiment (dico, puto, scio, video, gaudeo), de volonté (iubeo, veto, volo) et les tournures impersonnelles (constat, oportet, necesse est).
  • Sujet à l’accusatif, verbe à l’infinitif ; pas de « que » en latin.
  • Infinitif présent = simultané ; parfait = antérieur ; futur = postérieur.
  • Dico te venire : je dis que tu viens. Dixit se venisse : il dit qu’il était venu. Puto eum venturum esse : je pense qu’il viendra.
  • Sujet de l’infinitive = sujet principal → réfléchi se.

Ablatif absolu

  • Nom (ou pronom) + participe à l’ablatif, sans lien grammatical avec la principale.
  • Se traduit par une subordonnée (temps, cause, concession, condition) ou un complément.
  • Urbe capta, hostes fugerunt : la ville prise, les ennemis s’enfuirent.
  • Sans participe (sum n’en a pas) : Cicerone consule, sous le consulat de Cicéron ; Caesare vivo, du vivant de César.

Gérondif, adjectif verbal, supin

  • Gérondif = nom verbal (amandi, amando, ad amandum) ; au nominatif, on emploie l’infinitif. ars amandi, l’art d’aimer.
  • Avec un COD, l’adjectif verbal remplace le gérondif et s’accorde : cupidus urbis videndae, désireux de voir la ville.
  • Obligation : adjectif verbal + esse + datif de l’agent : Carthago delenda est, Carthage doit être détruite ; mihi legendum est, je dois lire.
  • Supin en ‑um après un verbe de mouvement (but) : pacem petitum venerunt, ils vinrent demander la paix ; en ‑u après un adjectif : facile dictu, facile à dire.

Style indirect

  • Paroles rapportées : les principales affirmatives passent à l’infinitive ; les ordres et les vraies questions, au subjonctif ; toutes les subordonnées, au subjonctif.
  • La 1re personne devient se, suus ; hic, nunc deviennent ille, tum ; temps selon la concordance.

Former le parfait

  • ‑vī, ‑uī : amo → amavi ; audio → audivi ; moneo → monui.
  • ‑sī, ‑xī : scribo → scripsi ; dico → dixi ; mitto → misi.
  • Allongement : lego → lēgi ; venio → vēni ; video → vīdi ; facio → fēci.
  • Redoublement : do → dedi ; sto → steti ; curro → cucurri ; cado → cecidi.
  • Sans changement : defendo → defendi ; verto → verti.
  • Formes contractes : amasti = amavisti ; amarunt = amaverunt ; audiit = audivit ; ‑ēre = ‑ērunt.

  • Mois (adjectifs) : Ianuarius, Februarius, Martius, Aprilis, Maius, Iunius, Iulius (anc. Quintilis), Augustus (anc. Sextilis), September, October, November, December.
