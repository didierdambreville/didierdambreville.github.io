L’interpréteur interactif

  • >>> invite ; ... suite d’un bloc — une ligne vide le termine.
  • _ rappelle le dernier résultat affiché.
  • ↑ ↓ historique ; Tab complète les noms.

Anatomie d’un programme

"""Aire d'un disque."""      1
import math                  2

RAYON = 2.5                  3

def aire(r):                 4
    """Renvoie l'aire du disque."""
    return math.pi * r ** 2  5

if __name__ == "__main__":   6
    print(f"{aire(RAYON):.2f}")  → 19.63
  • 1 docstring : documentation du module, lue par help() ;
  • 2 import d’un module de la bibliothèque standard ;
  • 3 constante : nom en majuscules (simple convention) ;
  • 4 définition de fonction : def, nom, paramètres, deux-points ;
  • 5 le bloc est délimité par l’indentation : 4 espaces ;
  • 6 exécuté seulement si le fichier est lancé, pas s’il est importé.

Syntaxe de base

  • Un bloc s’ouvre par : et se délimite par l’indentation : 4 espaces, sans mélange avec des tabulations.
  • Une instruction par ligne, sans ; final.
  • # commente jusqu’à la fin de la ligne.
  • Ligne trop longue : la couper à l’intérieur de ( ), [ ] ou { } plutôt qu’avec \.
  • La casse compte : nom ≠ Nom.
  • pass : bloc vide, à compléter plus tard.

match : filtrage par motif 3.10+

def analyser(cmd):
    match cmd.split():
        case ["aller", direction]:
            return f"vers {direction}"
        case ["prendre", *obj]:
            return f"{len(obj)} objets"
        case ["quitter" | "q"]:
            return "fin"
        case [n] if n.isdigit():
            return f"code {n}"
        case _:
            return "inconnu"

analyser("aller nord")   → 'vers nord'
analyser("prendre a b")  → '2 objets'
analyser("q")            → 'fin'
analyser("42")           → 'code 42'
analyser("")             → 'inconnu'
  • Motifs : littéral case 0:, alternative |, capture x, séquence [a, *reste], dictionnaire {"type": t}, classe Point(x=0), garde if.
  • case _: attrape tout le reste.
  • ! Un nom seul capture, il ne compare pas : case ROUGE: attrape tout. Comparer à une constante : nom pointé, case Couleur.ROUGE:

Portée des variables

Un nom est cherché dans l’ordre Local → fonction Englobante → Global (module) → Built-in (fonctions natives) : règle LEGB.

compteur = 0
def incrementer():
    global compteur       # sans cela : UnboundLocalError
    compteur += 1
incrementer()
compteur                  → 1

def fabrique():
    total = 0
    def ajouter(n):
        nonlocal total    # variable de la fonction englobante
        total += n
        return total
    return ajouter        # une « fermeture » (closure)
acc = fabrique()
acc(5), acc(3)            → (5, 8)

Préférer paramètres et valeurs de retour à global : le code reste lisible et testable.

Décorateurs

import functools, time

def chronometrer(f):
    @functools.wraps(f)            # conserve nom et docstring
    def enveloppe(*args, **kwargs):
        t0 = time.perf_counter()
        resultat = f(*args, **kwargs)
        duree = time.perf_counter() - t0
        print(f"{f.__name__} : {duree:.3f} s")
        return resultat
    return enveloppe

@chronometrer               # somme = chronometrer(somme)
def somme(n):
    return sum(range(n))

@functools.cache                   # mémorise les résultats
def fib(n):
    return n if n < 2 else fib(n - 1) + fib(n - 2)
fib(80)                            → 23416728348467685

class Compte:
    """Compte bancaire simple."""
    nb_comptes = 0                      # attribut de classe

    def __init__(self, titulaire, solde=0):

Héritage

class CompteEpargne(Compte):            # hérite de Compte
    def __init__(self, titulaire, solde=0, plafond=10_000):
        super().__init__(titulaire, solde)   # le parent d'abord
        self.plafond = plafond

    def deposer(self, montant):         # redéfinition
        if self.solde + montant > self.plafond:
            raise ValueError("plafond dépassé")
        return super().deposer(montant)

class Temperature:
    def __init__(self, celsius):
        self.celsius = celsius          # passe par le setter

    @property                           # lecture : t.celsius
    def celsius(self):
        return self._celsius

    @celsius.setter                     # écriture
    def celsius(self, valeur):
        if valeur < -273.15:
            raise ValueError("sous le zéro absolu")
        self._celsius = valeur

    @property
    def fahrenheit(self):               # attribut calculé
        return self._celsius * 9 / 5 + 32

    @classmethod                        # autre constructeur
    def depuis_fahrenheit(cls, f):
        return cls((f - 32) * 5 / 9)

    @staticmethod                       # ni self ni cls
    def gele(celsius):
        return celsius <= 0

def diviser(texte):
    try:
        n = int(texte)          # peut lever ValueError
        r = 100 / n             # peut lever ZeroDivisionError

    finally:                    # dans tous les cas
        print("fin")

    w.writerow(["nom", "note"])
    w.writerow(["Élise", 15])
with open("n.csv", newline="",
          encoding="utf-8") as f:
    lignes = list(csv.DictReader(
        f, delimiter=";"))
lignes[0]
→ {'nom': 'Élise', 'note': '15'}

JSON ↔ Python : objet ↔ dict, tableau ↔ list, true / null ↔ True / None. CSV : tout est lu comme texte ('15') ; newline="" obligatoire. Excel en français attend souvent ; et lit mieux les accents en encoding="utf-8-sig".

from datetime import date, datetime
from datetime import timedelta
d = date(2026, 1, 15)
d + timedelta(days=30)
→ datetime.date(2026, 2, 14)
(date(2026, 12, 25) - d).days  → 344
d.weekday()          → 3
d.strftime("%d/%m/%Y")  → '15/01/2026'
d.isoformat()           → '2026-01-15'
datetime.strptime("15/01/2026 14:30",
                  "%d/%m/%Y %H:%M")
→ datetime.datetime(2026, 1, 15, 14, 30)

weekday() : lundi = 0. date.today(), datetime.now() : aujourd’hui, maintenant. Codes : %Y année, %m mois, %d jour, %H %M %S heure, minute, seconde, %A nom du jour (anglais par défaut).

Style : PEP 8 et bonnes pratiques

  • 4 espaces par niveau ; lignes de 79 caractères au plus.
  • snake_case pour variables et fonctions, CapWords pour les classes, MAJUSCULES pour les constantes.
  • Deux lignes vides entre fonctions et classes de premier niveau.
  • is None plutôt que == None ; if liste: plutôt que if len(liste) > 0:
  • with pour les fichiers ; f-strings pour mettre en forme.
  • Fonctions courtes, noms explicites, docstrings.
  • Formatage et analyse automatiques : Ruff, Black ; types : mypy (outils tiers).
  • import this : les principes de Python (PEP 20).
